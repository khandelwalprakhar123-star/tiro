# Progress tracking — read & update `tracker.md`

`tracker.md` is the shared source of truth for project state across agents and sessions.

- **Before making changes:** read `tracker.md` to understand current state, decisions, and what's pending.
- **After making any meaningful change** (add/change/remove code, config, infra, or decisions): update
  `tracker.md` — append a dated Changelog entry and keep the Current State / Pending sections accurate.
- `prd.md` captures *intent* (what we're building); `tracker.md` captures *state* (what we've done). Keep
  both current. `prd-vision.md` is the full long-term reference spec.
